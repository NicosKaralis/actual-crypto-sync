# Dropped: one token across chains in one account

Dropped on 2026-11-19. Back to the [roadmap](../../ROADMAP.md#dropped).

**The idea:** one Actual account for one token on several chains. For example, USDT on TRON and USDT on Ethereum in one account.

**Why it was dropped:** an account has one chain and one token. For this idea, the chain and the token must move from the account to each wallet. That makes accounts with several wallets more difficult to configure and to check. We decided that one account holds one token on one chain.

To follow a token on several chains, use one account for each chain.
