# actual-crypto-sync

> **Work in progress.** Nothing is released yet, and the config format may still change before v1.0.0.

Keeps off-budget [Actual Budget](https://actualbudget.org) accounts in line with the value of your crypto wallets. Each run reads your wallets' balances and current prices, then writes one adjustment transaction per account per day, so the account shows what the wallet is worth.

Planned for v1.0: TRON (TRX and TRC20 tokens such as USDT) and Bitcoin, with more chains, block explorers and price providers added later.

Not affiliated with Actual Budget. It writes to your budget, so back it up first.
